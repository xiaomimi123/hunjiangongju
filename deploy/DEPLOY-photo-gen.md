# AI 实拍生图 部署清单

> 学员在「工具」页新入口拍书籍封面/内页照片，服务端按素材包提示词调图生图服务生成真实感种草照。
> 打包/上传/清旧解压/自动迁移沿用 [`CUTOVER.md`](./CUTOVER.md) 日常更新小节。本文只列本版特有事项。

## 0. 这个版本改了什么

| 变更 | 对存量的影响 |
|---|---|
| 学员端 /photo 三页 + 工具广场置顶入口 | 无，纯新增 |
| worker 新增 photo-gen 队列（并发 2） | 无，独立队列 |
| 数据库迁移 `20260916130000_photo_gen` | 纯新增一张表，秒级无锁 |
| 模型配置新增「实拍生图」能力卡 | 无，未配置时学员端提交会被 503 拒绝并提示联系运营 |

## 1. 部署命令

与常规更新一致（无新增依赖/环境变量）：本机 `git archive` → scp → 服务器清旧解压 → `up -d --build`，migrate 服务自动建表。

## 2. 部署后配置（必须，否则学员用不了）

后台 → 模型配置 → **实拍生图**：

- 接口地址：`https://api.apimart.ai`
- 密钥：apimart 的 sk- 密钥（**用于生产的正式密钥**，测试用过的那个已进过对话建议重新生成）
- 模型：`gpt-image-2`
- 高级参数（可选）：`{"resolution":"1k","pricePerImage":1}`
  - `resolution`：1k（默认，约 $0.0085/张）或 2k（更清晰更贵）
  - `pricePerImage`：学员每张消耗积分，默认 1
- 勾选启用 → 保存

**内页模式**还依赖 vision 能力（页面识别）与 `PUBLIC_BASE_URL`（vision 要公网拉图）——两者线上已配置，确认 vision 卡是启用状态即可。

## 3. 验收

1. 管理员账号（免扣分）进学员端「工具」→ 点「AI 实拍生图」；
2. 封面实拍：拍一张真实书封 → 智能推荐 → 1 张 → 生成 → 约 1 分钟出图，检查封面文字与手部；
3. 内页实拍：拍一张内页 → 清透窗光 → 生成 → 检查标题保真与胡桃木场景；
4. 学员账号跑一次确认扣分；随便传一张非书籍图片跑失败路径，确认积分退回；
5. `docker compose ... logs worker | grep photo` 看有无 `[photo] run ... done`。

## 4. 已知边界

- 单字错误：图像模型偶发个别字生成错误（实测「怀→杯」一例）——学员点「再生成一组」即可，属模型固有风险；
- 结果 URL 上游 24h 过期——worker 已转存本地 `data/photo-gen/`，无需处理；
- iPhone HEIC：上传只收 jpg/png/webp，iOS 网页上传一般自动转 JPEG，个别机型需在相机设置选「兼容性最佳」。
