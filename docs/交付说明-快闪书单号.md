# 东方文澜 · 快闪书单号生成工具 — 交付说明

> 版本：2026-07-29 交付版 · 访问地址：https://www.dfwl.top

## 一、产品是什么

一个**自动生成"快闪书单号"短视频**的工具。运营在后台配好文案，一键生成成片，发布到成片库，学员下载后即可发布/二次剪辑。

单条成片的固定结构（720×960 竖屏）：
1. **玻璃碎裂开场** +「今天分享的是」标题
2. **书单快闪**——逐本书封面快速闪过（书名弹出）
3. **叠化长镜头正片**——配图 + 逐句配音字幕 + **常驻《书名》大标题**
4. 全程 **背景音乐（BGM）+ 音效（齿轮/水滴）**，画面为**无人物**的治愈系艺术配图

---

## 二、角色与整体流程

| 角色 | 能做什么 |
|---|---|
| **运营** | 配文案 → 生成成片 → 发布到成片库；管理 BGM、学员、AI 模型配置 |
| **学员** | 在成片库浏览、下载运营发布的成片（去发布/二次剪辑） |

**主流程：** 运营【配文案生成】→【发布到成片库】→ 学员【下载成片】

## 三、运营操作指南

### 3.1 登录
浏览器打开 `https://www.dfwl.top`，用**运营账号**（邮箱/账号 + 密码）登录，进入后台。

### 3.2 生成一条书单号
进入后台「**生成**」→ 新建生成，依次：
1. **选择框架**：选已配置好的「快闪书单号」框架。
2. **文案来源**（本工具的核心）：
   - **手动粘贴**：把你写好的文案直接粘进去 → 成片文案**逐字就是你给的**，系统不改写。
   - **参考仿写**：粘一段参考文案 → AI 照它的风格/主题**仿写一版新文案**（找灵感/批量时用）。
3. **书名标题**：填这条视频要展示的书名（如「活着」），会作为正片常驻大标题。
4. （可选）主题、BGM 等。
5. 点**生成**，等待完成（依次经历 文案→配图→配音→渲染，需要 1~数分钟）。

> 文案建议：一句一断（句号/换行），系统按标点自动切分镜（一句一张图一句配音）。

### 3.3 发布到成片库
生成完成（状态 **已完成/EXPORTED**）后，进入该条的**生成详情**页，点「**发布**」。发布后即出现在学员端「成片库」。（未完成的成片不能发布。）

### 3.4 后台管理（按需）
- **BGM 曲库**（后台「BGM」）：**可多选批量上传**背景音乐、名字默认取文件名、可改名并按**文件夹**分组、标风格标签供生成时自动配乐。
- **素材库**（后台「素材库」）：**批量上传**现成的空镜头/封面图片（可分文件夹、改名）。生成时「配图来源」选**「素材库优先」**即优先用上传素材做画面，**素材不够的分镜自动 AI 生图补齐**。视频素材暂只存放不参与生成。
- **账号**（后台「学员数据」）：「**新增账号**」可手动创建**学员或运营**账号（注册关闭后加人全靠这里）；运营账号支持禁用/重置密码，系统会保护最后一名可用运营不被禁用。
- **画风预设**（后台「框架库」编辑）：画风一键预设「厚涂油画 / 梵高风 / 治愈插画」（填充后可再手改）；画风留空时默认厚涂油画。
- **克隆音色**：在火山「声音复刻2.0」控制台用对标音频克隆得 `S_` 开头音色 ID → 填入模型配置 tts 的 `extra` 中 `customVoices`（如 `{"customVoices":[{"id":"S_xxx","label":"对标男声"}]}`）→ 生成页音色下拉即可选用（系统自动走克隆专用通道）。
- **模型配置**（后台「模型配置」）：配置并启用 AI 能力（见第五节）。

---

## 四、学员操作指南
1. 用**学员账号**登录 `https://www.dfwl.top`。
2. 进入「**成片库**」，浏览运营发布的成片，在线预览。
3. 点「**下载 MP4**」保存视频（需要字幕可点「字幕 SRT」），下载后即可发布到各平台或二次剪辑。

## 五、系统配置（管理员）

### 5.1 AI 能力（必须启用才出真实内容）
后台「模型配置」逐项填写接口地址 + 密钥 + 模型名，测试连通后**启用**：

| 能力 | 接口地址 | 模型 | 用途 |
|---|---|---|---|
| llm 文案 | 百炼 | `qwen-plus` | 仿写文案 |
| image 文生图 | `https://dashscope.aliyuncs.com` | `wan2.7-image` | 场景图 / 书封底图 |
| tts 配音 | 见下（火山/百炼） | `seed-tts-2.0` / `qwen-tts` | 口播配音 |
| asr 转写 | `https://dashscope.aliyuncs.com` | `qwen3-asr-flash`（或 `paraformer-v2`） | **视频拆解**：口播转文字 |
| vision 视觉 | `https://dashscope.aliyuncs.com` | `qwen-vl-max` | **视频拆解**：识别画风/书名 |

> 未启用时走占位（空白图/静音/模拟文案）；**必须点"启用"**，且**配置修改后需重新生成**（不追溯旧任务）。
> **视频拆解依赖 asr（+vision）**：asr 与 image 同为百炼 DashScope，接口地址/密钥可与文生图相同，仅模型名不同；`qwen3-asr-flash` 可能需在百炼控制台开通。
> ⚠️ **视频拆解还要求服务器 `.env.prod` 配置 `PUBLIC_BASE_URL=https://<域名>`** —— 拆解要把音频以带签名的公网 URL 交给百炼拉取；缺此项转写会报 "PUBLIC_BASE_URL 未配置" 而拆解失败。
> qwen-tts 需在百炼控制台**开通**该产品，否则报"product is not activated"。
> **tts 已支持切换为火山（豆包语音合成大模型2.0）**：接口地址填 `https://openspeech.bytedance.com/api/v3/tts/unidirectional`，模型填 `seed-tts-2.0`（作为 X-Api-Resource-Id），密钥填**语音技术控制台的 API Key**（X-Api-Key，从 `控制台>API Key管理` 获取）。
> ⚠️ TTS 属**「语音技术」产品线，与火山方舟是两套、需单独开通**；方舟的 `ark-` key 在此**无效**。
> 音色为「豆包语音合成模型2.0」音色（已内置 7 个常用音色，可在生成时选择+试听；完整列表见控制台音色库）。情感/语气用 `extra.emotion`（自然语言语音指令，如「用温柔治愈的语气」）。

### 5.2 部署与运维
- 技术栈：Next.js（web）+ Node worker（BullMQ 任务队列）+ PostgreSQL + Redis + Caddy（HTTPS）+ ffmpeg + HyperFrames 渲染。AI 走阿里云百炼 DashScope。
- 服务器：阿里云，域名 `www.dfwl.top`；生产用 `docker-compose.prod.yml`。
- **更新发版 / 备份 / 回滚**：见 `deploy/CUTOVER.md`（日常更新小节）与 `deploy/DEPLOY-*.md`。核心流程 = 本机 `git archive` 打包 → scp 上传 → 服务器清旧代码解压 → `docker compose ... up -d --build`（迁移自动执行）。

## 六、已知限制与使用建议
- **生成需要时间**：一条约 1~数分钟（AI 生图 + 渲染），请耐心等待，别重复点。
- **生成期间界面可能短暂卡顿**：服务器为单台小规格，渲染时 CPU 占用高。建议**错峰生成**或**提前把要用的成片生成好**。
- **视频加载/下载速度取决于公网带宽**：当前带宽较低时在线播放会慢；建议**下载到本地播放/发布**，或提高服务器带宽。
- **字体**：当前用系统默认字体。若需客户原版排版（书名/字幕特定字体），请提供字体文件（`.ttf/.otf`）安装后即可内嵌。
- **书封美术风格**可在框架的画风配置里调整（如"极简性冷淡治愈系插画、无人物"）。

## 七、剪映模板（复刻同款风格）

后台「**剪映模板**」页支持上传客户的**剪映草稿** `draft_content.json`，系统自动解析其剪辑配方（画布、分镜节奏、转场、开场特效、字体排版、音效结构），生成一套**可复用的框架模板**；之后用该框架生成书单号，即套用同款风格（配 AI 新图 + 火山配音），无需逐条手调。

- 用法：后台「剪映模板」→ 上传 `draft_content.json`（草稿文件夹里的那个 JSON）→ 查看解析预览（时长/分镜数/需要的字体/识别到的书名/提示）→ 填框架名「保存为框架」→ 到「生成」里选它出片。
- **字体**：解析会列出草稿用到的字体名（如字由玄真/莫雪体）。要真正"同款字形"，需把对应 `.ttf` 放入 `worker/templates/booklist/fonts/`；未提供则用近似字体。
- 说明：只学"剪辑配方"，不复用客户原始图片/配音；首版针对书单快闪类结构。
- 「拆解」（旧的视频反推框架）入口已收起（代码保留），复刻请用「剪映模板」，精度更高。
