# 剪映工程深度拆解（结构节奏 + 调色 + 运镜 + 文字动画）设计

> 状态：设计定稿待评审 · 2026-08-06 · 分支 feat/shudan-m1
> 目标：让解析器读懂新版剪映工程（加密 + `text` 轨），并把**调色、逐段运镜、文字动画、画面缩放**这些决定观感的参数也确定性提取出来，落进模板参数由渲染层消费，把复刻度从「结构像」推到「质感像」。

## 一、触发与实测依据

用户上传新对标工程 `破碎的模板(1)`（@欧子好读 书单号）报 400。实测定位到两类问题，并以该工程与既有样例 `今天分享的是/` 双样本交叉验证了所有新判据。

**实测数据（新模板，`Timelines/507B4FBA-.../template.json`）**：iOS 剪映 19.1.0 · 834×1112(3:4) · 30fps · 33.5s
- 主视频轨 19 段：`seg0` 1500ms（video，玻璃聚集 in 1300ms）→ `seg1..13` 100–133ms（photo，快闪 13 张）→ `seg14` 1600ms（video，叠化+滑片滑动）→ `seg15..18` 6067/7033/8600/7233ms（photo，叠化）
- 转场：叠化 333/467/467/467ms
- 音频：`一滴水滴声`(sound, vol 2.75, @0) · `鼠标单击`(sound, vol 10, @5167) · `7.6.wav`(extract_music, vol 3.94, ×4 段=人声) · `复合片段6`(music, vol 3.29, 1667ms) · **`怎么说我不爱你（DJ前奏版）`(music, vol 0.4425, 33500ms=全片) = BGM**
- 文字（`text` 轨）：`今天分享的是`(x -0.316, y 0.374, 无动画) · `@欧子好读`(y -0.793, 波浪弹入 in 1500 + 逐字放大 loop) · `内容来自书评/感悟/素材来源于网络`(y -0.889, 波浪弹入 + 扫光 loop)
- 调色：filter `青橙`(影视级, value 0.503) · `锐化`(value 0) · `contrast` -0.2138 · HSL 自定义色 `#FFE64444`
- 关键帧：18 段带 `KFTypePositionX/Y`、1 段 `KFTypeScaleY`；显著者 `seg16` PositionX 0→0.125 / 7033ms（慢右移）、开场标题 ScaleY 1.169→1.214 / 2686ms（缓推）

- 复刻不了：3 层装饰图层（png 贴纸/微信图片/复合片段9）、剪映内置商用字体 `font.ttf`、剪映艺术蒙版

## 二、范围（已与用户确认）

第一档（结构类，渲染零改动）+ 第二档（观感类，需渲染层新增）全做。第三档（装饰图层/商用字体/蒙版）明确不做，解析报告里如实标注「无法复刻」。

### 非目标
- 不解析装饰图层、不内嵌商用字体、不复刻剪映蒙版。
- 不做剪映滤镜的像素级还原（拿不到剪映查找表，只做具名近似，见 §4）。
- 不做变速/卡点（本类工程未使用）。
- 不改 `TemplateParams` 既有字段语义（只加可选新字段），不改数据库结构。

## 三、第一档：解析判据加固

| 项 | 现状（失效原因） | 新判据（双样本验证） |
|---|---|---|
| 文字轨 | 只认 `track.type === 'sticker'` | 认 `sticker` 与 `text` 两种 |
| BGM | 素材名含「歌曲」且不含「提取」 | 排除 `type === 'sound'`（音效）后，取**音量有值且 < 1.0**（BGM 必被压在人声之下）中总覆盖时长最长者。新模板 0.4425 ✓ / 人声 3.94 ✗；旧样例 0.692 ✓ / 提取音乐轨无音量 ✗。名字规则降为兜底 |
| 三段结构 | 靠《书名》文字段推快闪 | 从主视频轨（`attribute === 1`）节奏推：首段=开场；其后连续 < 500ms 段的**最长连续段**=快闪；余下=正片。新模板 1+13+4、旧样例 1+9+3（旧样例 781ms 段落在正片侧，可接受） |
| 开场动画 | 名字匹配 `破镜|收拢` | 加 `玻璃|聚集|碎`（新模板为「玻璃聚集」） |
| 音效 | 只认 齿轮/旋钮、水滴 | 加 鼠标/单击/点击；`openGear`/`transitionDrop` 语义保持 |
| 水印 | 未提取 | `text`/`sticker` 中以 `@` 开头的文字 → 写入 `overlayTemplate.watermark`（渲染已支持） |
| 建议分镜数 | 未提取 | 正片段数 → `framework.suggestedSegmentCount` |
| 加密工程 | 无 | 前端：主 `draft_content.json` 非 `{` 开头时，自动改用 `Timelines/*/template.json` 明文版；都没有才报错 |

## 四、第二档：观感参数

`TemplateParams` 新增四组**可选**字段（缺省 = 现有行为，老框架零影响）：

```ts
grade?: { filterName: string; intensity: number; contrast: number; sharpen: boolean }
motion?: { moves: MoveId[] }                       // 按顺序循环用于正片段
flash?:  { …现有; scale?: number }                  // 快闪画面基准缩放
body?:   { …现有; photoScale?: number; subtitleEntrance?: EntranceId }
```

**① 调色**。提取 `materials.effects`：`type==='filter'` 取 `name`+`value`（强度）、`type==='contrast'` 取 `value`、`type==='sharpen'` 记布尔。渲染层内置一张**具名滤镜近似表**（首版仅收录实测到的 `青橙` = 冷青阴影 + 暖橙高光的经典电影感配方，用 SVG `feColorMatrix` 实现，Chromium 原生、确定性、seek-safe），按 `intensity` 线性插值到中性。**表中没有的滤镜名只套用 contrast/sharpen 数值，并在解析报告里提示「滤镜『X』未内置，已按对比度近似」**——不假装复刻。

**② 逐段运镜**。读每段 `common_keyframes` 的 `KFTypePositionX/Y`、`KFTypeScaleX/Y`，取首尾差值分类：|Δx| 最大且 >0.02 → `pan-right`/`pan-left`；|Δy| 最大且 >0.02 → `drift-up`（Δy<0 为上移，剪映 y 轴向上为负）/`tilt-settle`；Δscale >0.02 → `push-in`，<-0.02 → `pull-back`；均不显著 → 该段不产出。产出序列 `motion.moves`。渲染层：正片段的运镜改为**优先按 `moves` 顺序循环取**（生成视频分镜数与原工程不一致，严格一一对应无意义；循环保住节奏感），`moves` 为空时回落现有行为。

**③ 文字动画**。读文字段 `extra_material_refs` 指向的 `material_animations`，把剪映动画名映射到渲染层已有入场：`逐字放大|逐字` → `char-stagger`、`渐显|淡入` → `fade-up`、`点开|展开` → `mask-reveal`、`滑片滑动|滑入` → `slide-in`；多个文字段取出现最多者。产出 `body.subtitleEntrance`，渲染层**固定使用**该入场（对标账号通常一个套路到底，轮换反而不像）；缺省仍按序号轮换。

**④ 画面缩放**。取主视频轨快闪段 `clip.scale.x` 中位数 → `flash.scale`，正片段中位数 → `body.photoScale`（各自 clamp 到 1.0–2.0）。渲染层把它作为画面基准缩放，运镜的推拉在该基准上做（现为写死 1.035–1.2，改为基准 × 系数）。

## 八、风险与取舍

- **滤镜近似**：只有 `青橙` 一条内置配方，其他滤镜名只套数值。随实测样本增加逐步扩表；解析报告如实提示，避免"看起来复刻了其实没有"。
- **运镜循环**：分镜数不匹配时靠循环保节奏，不保证逐段对应——已与用户确认接受。
- **旧样例 781ms 段**：落在正片侧而非快闪侧，属边界判断；不影响该样例既有参数（其快闪参数仍由 9 个短段决定）。
