# 东方文澜 · 快闪书单号生成工具 — 交付说明

> 版本：2026-07-29 交付版 · 访问地址：https://www.dfwl.top

## 一、产品是什么

一个**自动生成"快闪书单号"短视频**的工具。运营在后台配好文案，一键生成成片，发布到成片库，学员下载后即可发布/二次剪辑。

单条成片的固定结构（720×960 竖屏）：
1. **玻璃碎裂开场** +「今天分享的是」标题
2. **书单快闪**——逐本书封面快速闪过（书名弹出）
3. **叠化长镜头正片**——配图 + 逐句配音字幕 + **常驻《书名》大标题**
4. 全程 **背景音乐（BGM）+ 音效（齿轮/水滴）**，画面为**无人物**的治愈系艺术配图

---

## 二、角色与整体流程

| 角色 | 能做什么 |
|---|---|
| **运营** | 配文案 → 生成成片 → 发布到成片库；管理 BGM、学员、AI 模型配置 |
| **学员** | 在成片库浏览、下载运营发布的成片（去发布/二次剪辑） |

**主流程：** 运营【配文案生成】→【发布到成片库】→ 学员【下载成片】

---

## 三、运营操作指南

### 3.1 登录
浏览器打开 `https://www.dfwl.top`，用**运营账号**（邮箱/账号 + 密码）登录，进入后台。

### 3.2 生成一条书单号
进入后台「**生成**」→ 新建生成，依次：
1. **选择框架**：选已配置好的「快闪书单号」框架。
2. **文案来源**（本工具的核心）：
   - **手动粘贴**：把你写好的文案直接粘进去 → 成片文案**逐字就是你给的**，系统不改写。
   - **参考仿写**：粘一段参考文案 → AI 照它的风格/主题**仿写一版新文案**（找灵感/批量时用）。
3. **书名标题**：填这条视频要展示的书名（如「活着」），会作为正片常驻大标题。
4. （可选）主题、BGM 等。
5. 点**生成**，等待完成（依次经历 文案→配图→配音→渲染，需要 1~数分钟）。

> 文案建议：一句一断（句号/换行），系统按标点自动切分镜（一句一张图一句配音）。

### 3.3 发布到成片库
生成完成（状态 **已完成/EXPORTED**）后，进入该条的**生成详情**页，点「**发布**」。发布后即出现在学员端「成片库」。（未完成的成片不能发布。）

### 3.4 后台管理（按需）
- **BGM 曲库**（后台「BGM」）：上传背景音乐 mp3、标风格标签，供生成时自动配乐。
- **学员**（后台「学员」）：新增/管理学员账号、重置密码。
- **模型配置**（后台「模型配置」）：配置并启用 AI 能力（见第五节）。

---

## 四、学员操作指南
1. 用**学员账号**登录 `https://www.dfwl.top`。
2. 进入「**成片库**」，浏览运营发布的成片，在线预览。
3. 点「**下载 MP4**」保存视频（需要字幕可点「字幕 SRT」），下载后即可发布到各平台或二次剪辑。

## 五、系统配置（管理员）

### 5.1 AI 能力（必须启用才出真实内容）
后台「模型配置」逐项填写接口地址 + 密钥 + 模型名，测试连通后**启用**：

| 能力 | 模型 | 用途 |
|---|---|---|
| llm 文案 | `qwen-plus` | 仿写文案 |
| image 文生图 | `wan2.7-image` | 场景图 / 书封底图 |
| tts 配音 | `qwen-tts` | 口播配音 |

> 未启用时走占位（空白图/静音/模拟文案）；**必须点"启用"**，且**配置修改后需重新生成**（不追溯旧任务）。
> qwen-tts 需在百炼控制台**开通**该产品，否则报"product is not activated"。
> **tts 已支持切换为火山（豆包 音频生成 seed-audio-1.0）**：接口地址填 `https://openspeech.bytedance.com/api/v3/tts/create`，模型填 `seed-audio-1.0`。凭据须来自**「语音技术」控制台**（TTS 属语音技术产品线，**与火山方舟是两套、需单独开通**；方舟的 `ark-` key 在此无效）：
> - **新版控制台**：密钥填 **X-Api-Key**（单头）。
> - **旧版控制台**：密钥填 **Access Token**，并在能力配置 `extra.appId` 填 **APP ID**（双头 X-Api-App-Id + X-Api-Access-Key）。
> 音色 speaker 用「豆包语音合成模型2.0」音色或声音复刻音色，需按**控制台可用音色**替换（默认占位音色仅供联调）。情感/语气可用 `extra.emotion`（自然语言，会前置到合成 Prompt）。

### 5.2 部署与运维
- 技术栈：Next.js（web）+ Node worker（BullMQ 任务队列）+ PostgreSQL + Redis + Caddy（HTTPS）+ ffmpeg + HyperFrames 渲染。AI 走阿里云百炼 DashScope。
- 服务器：阿里云，域名 `www.dfwl.top`；生产用 `docker-compose.prod.yml`。
- **更新发版 / 备份 / 回滚**：见 `deploy/CUTOVER.md`（日常更新小节）与 `deploy/DEPLOY-*.md`。核心流程 = 本机 `git archive` 打包 → scp 上传 → 服务器清旧代码解压 → `docker compose ... up -d --build`（迁移自动执行）。

## 六、已知限制与使用建议
- **生成需要时间**：一条约 1~数分钟（AI 生图 + 渲染），请耐心等待，别重复点。
- **生成期间界面可能短暂卡顿**：服务器为单台小规格，渲染时 CPU 占用高。建议**错峰生成**或**提前把要用的成片生成好**。
- **视频加载/下载速度取决于公网带宽**：当前带宽较低时在线播放会慢；建议**下载到本地播放/发布**，或提高服务器带宽。
- **字体**：当前用系统默认字体。若需客户原版排版（书名/字幕特定字体），请提供字体文件（`.ttf/.otf`）安装后即可内嵌。
- **书封美术风格**可在框架的画风配置里调整（如"极简性冷淡治愈系插画、无人物"）。
