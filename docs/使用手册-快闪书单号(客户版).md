# 快闪书单号生成工具 · 使用手册

> 访问地址：https://www.dfwl.top

## 一、这是什么

一个**自动生成"快闪书单号"短视频**的工具。你只需把文案填进去，系统就自动配图、配音、剪辑成片；发布后，学员即可下载去发布或二次剪辑。

**成片长这样（竖屏 720×960）：**
- 玻璃碎裂开场 +「今天分享的是」
- 书单封面快闪（逐本书名弹出）
- 正片：精美配图 + 逐句配音字幕 + 常驻《书名》大标题
- 全程背景音乐 + 音效

---

## 二、运营：生成并发布一条书单号

### 第 1 步 · 登录
浏览器打开 `https://www.dfwl.top`，用**运营账号**登录。

### 第 2 步 · 新建生成
进入「**生成**」，点新建，然后：

1. **选择框架**：选「快闪书单号」。
2. **文案来源**，二选一：
   - **手动粘贴**：把你写好的文案粘进去 —— 成片里的文案**一字不改，就是你给的**。
   - **参考仿写**：粘一段参考文案 —— 系统照它的风格帮你**写一版新文案**（想找灵感时用）。
3. **书名标题**：填这条视频要展示的书名（例如「活着」）。
4. 点 **生成**。

> 小贴士：文案尽量**一句一断**（用句号或换行分开），系统会按标点自动分镜，每句配一张图、一句配音。

### 第 3 步 · 等待完成
生成需要 **1～几分钟**（系统在写字幕、配图、配音、剪辑），请耐心等待，**不要重复点击**。完成后状态显示「**已完成**」。

### 第 4 步 · 发布到成片库
打开这条成片的详情页，点「**发布**」。发布后，学员就能在「成片库」看到并下载。

---

## 三、学员：下载成片

1. 用**学员账号**登录 `https://www.dfwl.top`。
2. 进入「**成片库**」，浏览运营发布的成片，可在线预览。
3. 点「**下载 MP4**」保存视频（需要字幕文件可点「字幕 SRT」）。
4. 下载后即可发布到各平台，或导入剪辑软件二次加工。

---

## 四、常见小提示

- **生成要等一会儿**：一条大约 1～几分钟，属正常，请勿反复点"生成"。
- **文案怎么写效果好**：一句一断、口语化、有画面感；开头一句先抓情绪。
- **要批量出片**：建议提前把成片生成、发布好，用时直接下载，最省心。
- **换背景音乐**：运营可在「BGM」里上传自己的音乐，生成时自动配乐。
